Logo study / second round

Lumo, simplified.

Six original symbols exploring a minimal robot and a dot based mark. Each is shown in light and dark, at full size and at 28 px. These are previews only; the app icon and in-app P are unchanged.

Robot direction

01Lens Bot

Wajah robot bulat dengan gagang kaca pembesar. Paling dekat dengan karakter Lumo.

02Visor Bot

Kepala robot dan dua mata; garis atas memberi kesan topi detektif tanpa detail ilustrasi.

03Scout Bot

Robot paling tegas dan simetris; cocok bila identitas aplikasi ingin terasa lebih teknis.

Dot direction

04Dot Lens

Rangkaian titik membentuk kaca pembesar; abstrak, tetapi masih mengacu pada Lumo.

05Dot P

Huruf P dari titik untuk menjaga hubungan dengan ikon aplikasi sebelumnya.

06Dot Scan

Medan titik dengan dua titik pusat sebagai mata; rujukan Lumo paling halus.

All six marks are original sketches. Select a direction for refinement before it is applied to the app.
