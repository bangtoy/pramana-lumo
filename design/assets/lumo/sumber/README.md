# Lumo — The Curious Field Companion

## Konsep karakter
Lumo adalah maskot berbentuk **kaca pembesar detektif yang hidup** untuk aplikasi **Agentic AI Field Monitoring**. Ia membantu petugas lapangan mencatat hasil observasi, menemukan anomali, memeriksa kelengkapan informasi, dan meminta klarifikasi atau bukti tambahan secara proaktif.

## Identitas visual
- **Siluet:** lensa kaca pembesar bundar besar sebagai wajah, dengan tangan dan kaki pendek.
- **Wajah:** mata ekspresif, pipi merah muda, dan senyum yang ramah.
- **Warna:** bingkai lensa biru, wajah putih kebiruan, aksen kuning-oranye, anggota tubuh gelap.
- **Aksesori:** topi detektif, rompi/kantong alat lapangan, dan papan identitas.
- **Gaya:** 3D cartoon / soft toy, rounded, menggemaskan, mudah dikenali.

## Kepribadian
Lumo penasaran, teliti, suportif, cepat tanggap, dan tidak menghakimi. Saat ada kesalahan, Lumo mengajak pengguna memeriksa ulang alih-alih menyalahkan.

## Ekspresi dan kegunaan file

| File | Ekspresi / state | Contoh penggunaan |
| --- | --- | --- |
| `00_lumo_hero.png` | Hero / greeting | Onboarding, welcome screen, empty state |
| `01_lumo_recording.png` | Recording / pencatatan | Saat mengisi atau merangkum laporan |
| `02_lumo_questioning.png` | Questioning / klarifikasi | Ketika informasi belum lengkap |
| `03_lumo_alert.png` | Alert / anomali | Saat mendeteksi data tidak konsisten atau masalah lapangan |
| `04_lumo_capture.png` | Capture / bukti visual | Meminta foto tambahan atau dokumentasi |
| `05_lumo_verified.png` | Verified / berhasil | Saat validasi dan pelaporan selesai |

## Contoh microcopy
- **Recording:** “Aku bantu rapikan catatan lapanganmu, ya!”
- **Questioning:** “Ada satu informasi yang belum lengkap. Bisa dicek lagi?”
- **Alert:** “Aku menemukan sesuatu yang perlu diperiksa.”
- **Capture:** “Boleh ambil satu foto tambahan dari sisi lain?”
- **Verified:** “Sip! Semua informasi sudah terverifikasi.”

## Catatan aset
Seluruh PNG merupakan **crop dari satu ilustrasi sumber** (bukan ilustrasi baru per ekspresi). Latar tetap putih, **bukan transparan**. Karena karakter ekspresi berada pada baris bawah ilustrasi, resolusinya lebih kecil daripada hero. Gunakan untuk prototipe/UI preview; untuk produksi resolusi tinggi atau animasi, sebaiknya render ulang tiap pose secara terpisah.
